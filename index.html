Install Blackout for Startpage

A true black theme and a few small add-ons for Startpage and SearXNG. Install only the parts you want. Click Install and your add-on opens a page where you confirm. The add-ons check for new versions by themselves.

Try the demo · How to use · Download for Windows

You need Stylus for the theme and Violentmonkey for the scripts. Tampermonkey works too.
On Chrome, Brave or Edge, open your extensions page, click Details under Violentmonkey and turn on Allow User Scripts. Without it the scripts do nothing.

  1. Blackout theme

    Black background and three accent colours. Results move a little toward the centre on wide screens. Hides ads and promos.

    theme/blackout.user.css · Stylus
    Install

  2. Blackout theme for SearXNG

    The same black theme and accent colours for any SearXNG instance. It only changes pages that say they are SearXNG. The scripts below work on SearXNG too.

    theme/blackout-searxng.user.css · Stylus
    Install

  3. Tweaks

    Results open in the same tab. The ad blocker banner and Private Search badge are hidden to reduce clutter. Every result gets a ⋮ menu to summarize it, open it in Anonymous View, copy the link, or pin or hide the site. Adds keyboard keys.

    scripts/tweaks.user.js
    Install

  4. Home widgets

    Clock, weather, shortcuts, notes, calendar, currency, timer and the next F1 race under the search box on the home page. Turn each one on or off, drag them into any order, resize them and pick your own colours.

    scripts/home.user.js
    Install

  5. Instant Answer

    A short answer above your results, written from those results, and one page summaries from the ⋮ menu. Continue it as a conversation that can search and read pages. Off until you turn it on. Works with any OpenAI-compatible service or a model app on your computer.

    scripts/instant-answer.user.js
    Install

  6. F1 card

    Formula 1 results with tyre strategy, standings and the race weekend schedule in your time zone. Shows the next race on the home page.

    scripts/f1.user.js
    Install

  7. Quick answers

    Timer, parcel tracking links, colour preview, coin flip, dice, random numbers, currency and a shortcut to Startpage's own translator.

    scripts/quick.user.js
    Install
