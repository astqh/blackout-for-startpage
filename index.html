Install Blackout for Startpage

A true-black theme and a few userscripts for Startpage. Install only the parts you want. Click Install: your add-on opens its own page asking you to confirm. Clicking Install again later updates that part, and the add-ons also check for new versions by themselves.

You need: Stylus for the theme, and Violentmonkey (or Tampermonkey) for the scripts.
Chrome, Brave, Edge: open the add-on's details in your browser's extensions page and turn on Allow User Scripts, or the scripts silently do nothing.

  1. Blackout theme

    True-black look, three accent colours, results moved centre-left on wide screens (or left or centred).

    theme/blackout.user.css · Stylus
    Install

  2. Tweaks

    Results open in the same tab, no ad-blocker banner, no Private Search badge. A ⋮ menu on every result (summary, Anonymous View, copy link, pin or hide a site) and keyboard keys.

    scripts/tweaks.user.js
    Install

  3. Home widgets

    Clock, weather, shortcuts, notes, calendar, currency, timer and the next F1 race under the home-page search box. Turn each on or off and drag them around.

    scripts/home.user.js
    Install

  4. Instant Answer

    A short AI answer above your results, and one-page summaries from the ⋮ menu. Off until you turn it on with your own provider: OpenCode Go or a model on your PC.

    scripts/instant-answer.user.js
    Install

  5. F1 card

    Formula 1 results with tyre strategy, standings and the weekend schedule in your time zone, and the next race on the home page.

    scripts/f1.user.js
    Install

  6. Quick answers

    Timer, parcel tracking buttons, colour preview, coin, dice, random numbers, currency, and translation searches sent to Startpage's own translator.

    scripts/quick.user.js
    Install
